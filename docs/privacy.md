# 隐私、安全和限制

## 数据生命周期

静态网页用 File API 读取文件，本地 Worker 解析、匹配。没有上传接口、云数据库、AI、统计、广告、会话录制、第三方字体或 CDN 脚本。依赖和 PDF 线程打包成同源资源。

不使用 localStorage、sessionStorage、IndexedDB、Service Worker 保存流水。刷新、关闭或清除数据会丢弃会话并终止处理。取消任务保留之前已确认版本，不应用半成品。解析库按需加载只产生同源静态 GET，不携带账单内容。

仅主动导出才生成本地下载。清除会话不删除已下载报告。浏览器 / 操作系统的内存、交换区或下载管理不由本应用控制。

长数字账号默认脱敏，摘要按 React 文本渲染，不能执行 HTML。编辑账户输入框时可见所输入值。金额、摘要、备注仍敏感，共享屏幕时需留意。生产日志不输出流水、姓名、卡号或摘要。

## 输入与资源保护

- 单文件 10 MiB，一次最多 15 文件；单文件约 20,000 行（另留 100 行说明），会话最多 50,000 原始行。
- 最多 20 工作表、100 列、每单元格 10,000 字符；PDF 最多 30 页、1,000,000 文本字符。
- XLSX 流式计算实际解压量，最多 30 MiB / 500 内部文件。检查重复内部文件、稀疏超大行列、XML 实体、公式、宏、外部链接和嵌入对象。
- XLS 检查 BIFF 签名、读取行数及原始范围，拒绝公式、超链接、宏和加密文件。
- PDF 只提取文本，不运行表单脚本 / 文档动作，不渲染图片、不跟随链接、不 OCR。图像、加密或未知布局拒绝。CSP 禁止远端脚本 / 资源及对象嵌入。
- 任务 30 秒超时终止，候选组合最多 200,000 对。
- CSV 对 = + - @、前导空白 / 控制字符和对应全角触发字符加文本前缀，所有字段按 CSV 规则引用。输入 Excel 公式不执行，要求另存为纯值文件。

限额是资源控制措施，不保证任意恶意文件绝对安全。超限应分账期导出，不能关闭校验绕过。

## 公开仓库

.gitignore 排除环境文件、真实账单目录、上传目录、本地数据、数据库、日志、构建产物及私有验证目录。任意命名文件仍可能被误提交，发布前必须检查文件清单。

tests/fixtures/、测试和 src/demo.ts 只包含人工构造数据。真实样本从仓库外上传目录读取验证，不产生公开快照或构建资源。公开代码不等于公开账单。

## 产品边界

不自动改随手记、不登录银行、不抓取 Cookie / 验证码、不支付，无后台数据库。暂不提供 Excel 报告（可导出 CSV）、OCR、持久化、多对多匹配、无边界组合搜索、AI 裁决和全部银行模板识别。复杂转账、还款和微信 / 银行跨渠道关系由用户核实。疑似差异不是账本确定记错。
