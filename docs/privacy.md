# 数据保存与隐私

第二阶段默认是私人服务器模式。登录后，账单提取的原始表格内容、标准化流水、账户关联、期初余额、人工复核及备注通过同源 API 保存到用户自己的 MySQL。文件仍在浏览器 Worker 内读取与初次解析，后端保存时会再次按字段映射标准化。

数据库包含财务信息。普通银行文件保存完整提取表格；微信只将零钱支出作为有效对账记录，其他行仍保留于原始表格以便追溯。原始 XLS / XLSX / PDF 二进制文件不上传或保存。不会向 AI、银行或第三方 API 发送内容，没有统计、广告或会话录制。

密码存为带随机盐的 scrypt 摘要，登录 Cookie 为 HttpOnly、SameSite=Strict，生产环境启用 Secure。服务器仅保存随机会话令牌的 SHA-256 摘要。登录 12 小时有效，退出会撤销服务端会话。浏览器 localStorage、sessionStorage、IndexedDB 均不保存密码和流水。

刷新或下次登录恢复已保存的工作区。自动保存失败或版本冲突会明确提示，离开前应确认保存状态。从当前工作区移除文件、清空工作区不会删除数据库账单。永久删除需单独确认，删除账单及关联记录，保留操作审计。下载的 CSV 仍保存在用户设备上。

审计记录时间、账号、来源 IP、事件、结果、对象编号以及记录数量。日志不包含密码、会话密钥、交易明细或复核备注。数据库管理员的直接操作不经过网站审计；数据库备份与运维由部署人员管理。

所有数据库、初始管理员及证书配置只由后端 `.env` 读取，不使用 `VITE_` 前缀。`.env`、私有验证数据、账单、数据库、日志、证书与构建目录默认被 Git 忽略。不得将真实账单或凭据提交到公开仓库。

明确使用 `VITE_APP_MODE=local` 构建的本地模式仍不调用后端、不保存数据库，刷新清空数据。它用于旧流程测试或离线试用，不能作为服务器模式部署；生产构建默认显示登录界面。详见 [Hermes 部署说明](deployment.md)。

随手记自动同步尚未配置，目前通过导入快照更新。不会登录或修改随手记网站，不执行支付或银行交易。账单适配、日终余额规则、信用卡文本 PDF 和文件资源限额仍遵循现有文档。

跨文件去重保留原始副本和来源位置，仅标记哪些记录不参与计算。公司 / 对公账户不会按名称猜测关联，未知银行模板须确认，已知来源冲突会拒绝保存。
